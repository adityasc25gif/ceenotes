How to make this permanent (5 minutes)

Follow once. After that your files and this vault live forever for free.

Method 1 — GitHub Releases (Best)

1
Create free GitHub account → New repository
2
Go to Releases → Create release → Upload files (up to 2 GB each)
3
Copy the download URL → paste it in the Permanent Links tab
4
Host this website on GitHub Pages so you can open it from any device
# Push this website to your repo: git init git add . git commit -m "FileVault website" git branch -M main git remote add origin https://github.com/YOUR_USERNAME/filevault.git git push -u origin main # Then: Settings → Pages → Deploy from main branch

Method 2 — Google Drive

1
Upload files to Google Drive
2
Right-click → Share → Anyone with the link → Copy link
3
Paste the link into Permanent Links tab (choose “Google Drive”)

Pro Tip

Use GitHub Releases for important permanent archives + Google Drive for quick sharing. All permanent links you save here are stored in your browser’s localStorage so they stay even after refresh.
